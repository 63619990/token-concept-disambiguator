# 通证/代币化概念辨析器（Web3 防骗工具箱）

> 本技能由《价值互联网产业应用蓝皮书（2025）》经 cangjie-distill 蒸馏流水线提取编排，帮助普通用户识别真假 Web3、厘清合规边界、避开资金盘陷阱。

## 功能简介
当用户/创作者混淆"上链""发币""RWA""通证化/代币化"等概念，或需判断某说法属于通证化、代币化、RWT/RWAT/RDA 哪一层、是否触碰金融属性时使用。不适用于：纯粹合规判定（转 S2 合规红线）、真伪 Web3 项目识别（转 S4 W-ABCD）、具体 RWA 落地流程（转 S8）。

## 安装方式

### 方式一：从 ClawHub 一键安装（推荐）
在 ClawHub 搜索 `token-concept-disambiguator`，或用 CLI：
```bash
clawhub skill install token-concept-disambiguator
```

### 方式二：从 GitHub 安装
```bash
git clone https://github.com/63619990/token-concept-disambiguator.git
cp -r token-concept-disambiguator/ ~/.workbuddy/skills/
```
重启 WorkBuddy 后，对话出现相关信号即自动激活。

### 方式三：手动安装
将本仓库 `token-concept-disambiguator/` 目录整体复制到 `~/.workbuddy/skills/`（Windows 为 `%USERPROFILE%\.workbuddy\skills\`）。
